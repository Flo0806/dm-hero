# Erste Schritte

Willkommen bei **DM Hero** - deinem ultimativen D&D Kampagnen-Begleiter! Diese Anleitung bringt dich in kürzester Zeit zum Profi in Sachen Kampagnen-Management.

## Was ist DM Hero?

DM Hero ist ein **lokal-erstes** Kampagnen-Management-Tool, speziell für Spielleiter entwickelt. Es hilft dir:

- 📝 NPCs, Orte, Gegenstände, Fraktionen, Wissen und Sessions zu organisieren
- 🔗 Verbindungen zwischen allem in deiner Welt zu erstellen
- 🔍 Alles sofort mit leistungsstarker Fuzzy-Suche zu finden
- 🗺️ Standorte auf interaktiven Kampagnenkarten zu verfolgen
- 📅 Deinen In-Game-Kalender und Session-Verlauf zu verwalten
- 🤖 Namen und Bilder mit KI zu generieren (optional)

**Das Beste**: Deine Daten bleiben auf DEINEM Rechner. Keine Cloud, keine Abos, kein Data Mining.

## Installation

### Option 1: Desktop-App (Empfohlen)

Der einfachste Weg, DM Hero zu nutzen:

1. **Lade** die neueste Version aus dem [Download-Bereich](/#download) herunter
2. **Entpacke** die ZIP-Datei (Windows)
3. **Starte** `DM Hero.exe`
4. **Fertig!** Deine Daten werden automatisch lokal gespeichert

> **Tipp**: Hefte DM Hero an deine Taskleiste für schnellen Zugriff während der Sessions!

### Option 2: Docker (Self-Hosted)

Für technikaffine Nutzer, die DM Hero auf einem Server betreiben wollen:

```bash
# Das neueste Image herunterladen
docker pull ghcr.io/flo0806/dm-hero

# Mit persistenten Daten starten
docker run -d \
  --name dm-hero \
  -p 3000:3000 \
  -v dm-hero-data:/app/data \
  ghcr.io/flo0806/dm-hero
```

Dann öffne `http://localhost:3000` in deinem Browser.

## Erster Start

Wenn du DM Hero zum ersten Mal öffnest, siehst du ein leeres Dashboard. Das ändern wir jetzt!

### Schritt 1: Erstelle deine Kampagne

1. Klicke auf den **+**-Button oder **"Neue Kampagne"**
2. Gib einen Namen ein (z.B. "Fluch des Strahd" oder "Meine Homebrew-Welt")
3. Optional: Füge eine Beschreibung hinzu
4. Klicke auf **Speichern**

Deine Kampagne ist jetzt aktiv und bereit für Inhalte!

### Schritt 2: Füge deinen ersten NPC hinzu

NPCs sind oft das Herzstück jeder Kampagne. Lass uns einen erstellen:

1. Klicke auf **NPCs** in der Seitenleiste
2. Klicke auf den **+**-Button
3. Fülle die Details aus:
   - **Name**: Der Name des NPCs (z.B. "Gandalf der Graue")
   - **Rasse**: Elf, Zwerg, Mensch, etc.
   - **Klasse**: Kämpfer, Magier, Schurke, etc.
   - **Beschreibung**: Nutze Markdown für Formatierung!
4. Klicke auf **Speichern**

> **Profi-Tipp**: Du kannst ein Porträt-Bild hochladen oder den KI-Bildgenerator nutzen!

### Schritt 3: Erstelle einen Ort

Jeder NPC braucht einen Ort:

1. Klicke auf **Orte** in der Seitenleiste
2. Klicke auf den **+**-Button
3. Gib ein:
   - **Name**: "Das Tänzelnde Pony"
   - **Typ**: Taverne
   - **Beschreibung**: Beschreibe die Atmosphäre, Gerüche, Geräusche...
4. Klicke auf **Speichern**

### Schritt 4: Verknüpfe sie miteinander

Hier passiert die Magie! Sagen wir, Gandalf besucht regelmäßig die Taverne:

1. Öffne den NPC "Gandalf"
2. Gehe zum Tab **Beziehungen**
3. Klicke auf **Beziehung hinzufügen**
4. Wähle "Das Tänzelnde Pony" als Ziel
5. Setze den Beziehungstyp (z.B. "besucht regelmäßig" oder "wohnt in")
6. Speichern

Wenn du jetzt eine der Entitäten anschaust, siehst du, dass sie verbunden sind!

## Das Dashboard

Dein Dashboard zeigt:

- **Aktive Kampagne**: Wechsle einfach zwischen Kampagnen
- **Letzte Entitäten**: Schneller Zugriff auf kürzlich angesehene/bearbeitete Einträge
- **Schnelle Statistiken**: Wie viele NPCs, Orte, etc. du hast
- **Letzte Sessions**: Springe zurück zu deinen Session-Notizen

## Navigation

### Seitenleiste

Die Seitenleiste gibt dir schnellen Zugriff auf alle Entitätstypen:

| Icon | Bereich | Was es enthält |
|------|---------|----------------|
| 👤 | NPCs | Nicht-Spieler-Charaktere |
| 📍 | Orte | Plätze in deiner Welt |
| ⚔️ | Gegenstände | Waffen, Rüstungen, Artefakte |
| 🛡️ | Fraktionen | Gilden, Organisationen, Königreiche |
| 📚 | Wissen | Weltenbau-Wissen |
| 🎭 | Spieler | Deine echten Spieler und ihre Charaktere |
| 📅 | Sessions | Spielsitzungs-Notizen und -Verlauf |
| 🗺️ | Karten | Interaktive Kampagnenkarten |

### Globale Suche

Drücke **`/`** (Schrägstrich) irgendwo, um die globale Suche zu öffnen. Tippe irgendetwas und DM Hero findet es - sogar mit Tippfehlern!

## Tipps für Erfolg

### 1. Fang klein an

Versuche nicht, deine ganze Welt auf einmal zu dokumentieren. Füge Entitäten hinzu, wenn sie in deinen Sessions relevant werden.

### 2. Nutze Entity-Linking

In jedem Beschreibungsfeld, tippe `{{` um zu anderen Entitäten zu verlinken:

```markdown
Der {{npc:Gandalf}} wurde zuletzt im {{location:Tänzelnden Pony}} gesehen,
mit dem {{item:Stab der Macht}} in der Hand.
```

Diese werden zu klickbaren Links mit Hover-Vorschauen!

### 3. Füge Bilder hinzu

Visuelle Referenzen helfen enorm:
- Lade Charakter-Porträts für NPCs hoch
- Füge Karten für Orte hinzu
- Füge Gegenstands-Illustrationen ein

### 4. Nutze den Chaos-Graphen

Klicke auf das Graph-Icon bei jeder Entität, um alle ihre Verbindungen visualisiert zu sehen. Es ist unglaublich hilfreich zu verstehen, wie deine Welt zusammenpasst.

### 5. Regelmäßige Backups

Deine Daten werden in einer SQLite-Datenbank gespeichert. Der Dateipfad:
- **Windows**: `%APPDATA%/dm-hero/data/dm-hero.db`
- **Docker**: In deinem gemounteten Volume

Kopiere diese Datei regelmäßig für Backups!
