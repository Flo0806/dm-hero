## Fuzzy-Suche

### Das Problem

Du bist mitten in der Session. Ein Spieler fragt "Wie hieß nochmal dieser NPC? Der in Baldurs Tor?" Du weißt, es war irgendwas wie "Elminster", aber du erinnerst dich nicht genau...

### Die Lösung

Drücke **`/`** und tippe "Elminstr" - DM Hero findet "Elminster" trotz deines Tippfehlers!

### Wie es funktioniert

DM Hero nutzt **FTS5** (Full-Text Search 5) kombiniert mit **Levenshtein-Distanz**-Matching:

- **FTS5**: Indiziert all deine Inhalte für sofortiges Abrufen
- **Levenshtein**: Misst wie "nah" deine Suche an echten Namen ist
- **Cross-Entity**: Durchsucht NPCs, Orte, Gegenstände... alles!

### Suchtipps

| Was du tippst | Was gefunden wird |
|---------------|-------------------|
| `gandlf` | Gandalf (Tippfehler-tolerant) |
| `magier elf` | Alle Elfen-Magier |
| `"tänzelndes pony"` | Exakte Phrasen-Übereinstimmung |
| `taverne wassertiefe` | Tavernen in Wassertiefe |

### Metadaten-Suche

Die Suche umfasst auch Metadaten-Felder:

- Suche "elf magier" um NPCs mit Rasse=Elf UND Klasse=Magier zu finden
- Suche "legendär waffe" um legendäre Seltenheits-Waffen zu finden
- Suche "rechtschaffen gut" um alle Rechtschaffen Guten NPCs zu finden

## Entity-Linking

### In-Text-Referenzen

In jedem Beschreibungsfeld kannst du klickbare Links zu anderen Entitäten erstellen:

```markdown
Der {{npc:Gandalf}} traf sich mit {{npc:Frodo}} in {{location:Beutelsend}}.
Er trug den {{item:Stab der Macht}} und sprach über {{lore:Der Ring}}.
```

### Wie man es nutzt

1. Tippe `{{` in ein beliebiges Beschreibungsfeld
2. Wähle den Entitätstyp: `npc`, `location`, `item`, `faction`, `lore`, `player`
3. Tippe den Entitätsnamen
4. Schließe mit `}}`

### Was du bekommst

- **Klickbare Badges**: Klicken um direkt zu navigieren
- **Hover-Vorschauen**: Sieh Entitätsdetails ohne die Seite zu verlassen
- **Automatische Updates**: Wenn du eine Entität umbenennst, aktualisieren sich die Links
- **Bidirektionales Bewusstsein**: Verknüpfte Entitäten wissen voneinander

### Beispiel-Workflow

Schreiben über einen Ort:

```markdown
## Das Tänzelnde Pony

Ein berühmtes Gasthaus in {{location:Bree}}. Der Wirt {{npc:Gerstenmann Butterblümchen}}
serviert das beste Ale der Region.

Gerüchten zufolge treffen sich {{faction:Die Waldläufer}} hier oft im Geheimen,
und die {{item:Mysteriöse Karte}} wurde zuletzt im Hinterzimmer gesehen.
```

## Kampagnenkarten

### Überblick

Lade deine Weltkarten hoch und mache sie interaktiv!

### Erste Schritte

1. Gehe zu **Karten** in der Seitenleiste
2. Klicke auf **Karte hochladen**
3. Wähle ein Bild (PNG, JPG, WebP)
4. Gib einen Namen und eine Beschreibung ein

### Marker platzieren

1. Öffne eine Karte
2. Klicke den **+**-Button → **Marker hinzufügen**
3. Klicke auf die Karte wo du den Marker haben willst
4. Wähle eine Entität zum Verknüpfen
5. Speichern!

Marker sind **farbcodiert nach Entitätstyp**:
- 🟢 NPCs (Grün)
- 🔵 Orte (Blau)
- 🟠 Gegenstände (Orange)
- 🟣 Fraktionen (Lila)

### Ortsbereiche

Markiere Regionen auf deiner Karte:

1. Klicke **+** → **Bereich hinzufügen**
2. Klicke auf den Mittelpunkt
3. Passe den Radius an
4. Verknüpfe mit einer Orts-Entität

Toll um Stadtviertel, Waldgrenzen oder Territorien zu zeigen!

### Messwerkzeug

Musst du Entfernungen wissen?

1. Klicke das **Lineal-Icon**
2. Klicke Punkte auf der Karte (A → B → C)
3. Sieh die berechnete Gesamtdistanz!

**Wichtig**: Setze den Maßstab deiner Karte im Bearbeiten-Dialog:
- Kartenmaßstab (z.B. "100 km breit")
- Einheitentyp (km, Meilen, Meter)

### Kartenfunktionen

- **Schwenken & Zoomen**: Flüssige Navigation
- **Marker ziehen**: Jederzeit neu positionieren
- **Nach Typ filtern**: Nur NPCs zeigen, nur Gegenstände, etc.
- **Entitäten-Labels**: Namen erscheinen beim Reinzoomen
- **Persistenter Zoom**: Merkt sich deine Zoomstufe pro Karte

## Chaos-Graph

### Was ist das?

Eine visuelle Darstellung der Verbindungen einer Entität. Klicke auf das **Graph-Icon** bei jeder Entität um es zu sehen.

### Den Graphen lesen

- **Zentrum**: Deine ausgewählte Entität (hervorgehoben)
- **Umgebende Knoten**: Verbundene Entitäten
- **Durchgezogene Linien**: Direkte Beziehungen
- **Gestrichelte Linien**: Querverbindungen (wie umgebende Entitäten untereinander verbunden sind)

### Interaktion

- **Hover** über einen Knoten: Hebt seine Verbindungen hervor
- **Klick** auf einen Knoten: Navigiere zum Chaos-Graphen dieser Entität
- **Filter-Chips**: Entitätstypen ein-/ausblenden
- **Ansehen/Bearbeiten-Buttons**: Schnellaktionen beim Hover

### Warum "Chaos"?

Weil eine gut entwickelte Kampagnenwelt wunderschön chaotisch aussieht! All diese verbundenen NPCs, Orte, Gegenstände und Fraktionen erzeugen ein Beziehungsnetz.

### Anwendungsfälle

1. **Session-Vorbereitung**: Sieh alle Verbindungen vor einer Session
2. **Improvisation**: Finde schnell verwandte NPCs mitten im Spiel
3. **Weltenbau**: Entdecke Lücken in deinen Verbindungen
4. **Spielerfragen**: "Wer weiß von dem Artefakt?" - visualisiere es!

## In-Game-Kalender

### Das Problem

"Warte, wie viele Tage sind vergangen seit wir Wassertiefe verlassen haben?"

### Die Lösung

DM Hero verfolgt die interne Timeline deiner Kampagne.

### Einrichtung

1. Gehe zu **Einstellungen** → **Kalender**
2. Definiere deinen Kalender:
   - Monatsnamen
   - Tage pro Monat
   - Startdatum

### Den Kalender nutzen

Beim Erstellen von **Sessions** setzt du das In-Game-Datum. DM Hero verfolgt:

- Wie viele Tage vergangen sind
- Was an welchem Tag passiert ist
- Zeit zwischen Ereignissen

### Session-Timeline

Betrachte Sessions auf einer Timeline die zeigt:
- Real-World-Daten (wann ihr gespielt habt)
- In-Game-Daten (wann es in der Geschichte passierte)
- Dauer der In-Game-Zeit

## KI-Integration (Optional)

### Voraussetzungen

- OpenAI API-Schlüssel (hole einen auf [openai.com](https://openai.com))
- Trage ihn ein unter **Einstellungen** → **KI**

### Namensgenerierung

Bei einem Namen hängengeblieben? Klicke das **Zauberstab-Icon**:

- **NPCs**: Generiere Namen gefiltert nach Rasse
- **Orte**: Generiere Namen nach Typ (Stadt, Taverne, etc.)
- **Gegenstände**: Generiere Fantasy-Gegenstandsnamen
- **Fraktionen**: Generiere Organisationsnamen

### Bildgenerierung

Erstelle Porträts und Szenen mit DALL-E:

1. Öffne eine Entität
2. Klicke **Bild generieren**
3. Optional: Füge einen eigenen Prompt hinzu
4. Warte auf die Magie! ✨

**Tipps für bessere Bilder**:
- Sei spezifisch: "älterer zwergischer Schmied mit geflochtenem Bart"
- Erwähne die Umgebung: "in einer schwach beleuchteten Schmiede"
- Nenne den Stil: "Fantasy-Kunststil, detailliert"

### Datenschutz-Hinweis

Bei Nutzung der KI-Features:
- Dein Prompt wird an OpenAI gesendet
- Generierte Inhalte werden lokal gespeichert
- Keine anderen Daten werden geteilt

## Daten & Privatsphäre

### Lokal gespeichert

Alle deine Daten bleiben auf **deinem Rechner**:

- **Desktop-App**: `%APPDATA%/dm-hero/`
- **Docker**: In deinem gemounteten Volume
- **Keine Cloud-Sync**: Deine Daten verlassen nie deinen Computer

### Datenbank

DM Hero nutzt **SQLite** - eine robuste, bewährte Datenbank:

- Einzelne Datei: `dm-hero.db`
- Einfach zu sichern: Einfach die Datei kopieren
- Kein Server nötig
- Funktioniert offline

### Soft-Delete

Wenn du etwas löschst, ist es nicht wirklich weg:

- Als gelöscht markiert (wiederherstellbar)
- Aus der Ansicht ausgeblendet
- Kann bei Bedarf wiederhergestellt werden

### Export/Backup

Regelmäßige Backups empfohlen:

```bash
# Finde deine Datenbank
# Windows: %APPDATA%/dm-hero/data/dm-hero.db
# Docker: dein-volume/dm-hero.db

# Kopiere zum Backup-Ort
cp dm-hero.db dm-hero-backup-$(date +%Y%m%d).db
```

## Tipps & Tricks

### 1. Nutze Vorlagen

Erstelle einen "Vorlage-NPC" mit ausgefüllten Standard-Feldern. Kopiere ihn beim Erstellen neuer NPCs.

### 2. Konsistente Benennung

Nutze konsistente Namenskonventionen:
- Orte: "Der/Die/Das [Name]" oder einfach "[Name]"
- NPCs: "Vorname Nachname" oder "Spitzname"
- Gegenstände: "Der/Die/Das [Adjektiv] [Gegenstand]" für legendäre Items

### 3. Mit Beziehungen taggen

Statt Tags zu nutzen, verwende Beziehungen:
- Erstelle eine Fraktion "Questgeber"
- Füge alle questgebenden NPCs als Mitglieder hinzu
- Jetzt kannst du sie alle einfach finden!

### 4. Session-Vorbereitungs-Workflow

1. Überprüfe den Chaos-Graphen für Schlüssel-NPCs
2. Überblicke verwandte Orte
3. Notiere wichtige Gegenstände
4. Bereite Fraktionsbewegungen vor

### 5. Nach-Session-Routine

1. Erstelle einen Session-Eintrag
2. Aktualisiere NPC-Status (tot? umgezogen?)
3. Aktualisiere Gegenstands-Orte (wer hat jetzt was?)
4. Füge neue NPCs/Orte hinzu die vorkamen
